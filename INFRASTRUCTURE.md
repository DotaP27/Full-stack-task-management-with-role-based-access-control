# Infrastructure as Code for Railway Deployment

## Files for deployment

This directory contains the necessary configuration files for deploying to Railway.

### Docker Configuration
- `backend/Dockerfile` - Docker image for FastAPI backend
- `frontend/Dockerfile` - Docker image for React frontend
- `docker-compose.yml` - Local development with Docker

### Environment
- `.env.example` files in backend/ and frontend/ - Template for environment variables
- `.gitignore` - Files to ignore in git

### Documentation
- `README.md` - Full project documentation
- `QUICK_START.md` - Quick start guide
- `DEPLOYMENT_GUIDE.md` - Detailed deployment instructions

### Scripts
- `setup.sh` - Automated setup for macOS/Linux
- `setup.bat` - Automated setup for Windows
