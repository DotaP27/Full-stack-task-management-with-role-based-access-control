## 🎨 Design System

### Color Palette
```
Primary: Purple-Pink-Blue Gradients
Success: Green (#10b981)
Warning: Yellow (#f59e0b)
Danger: Red (#ef4444)
Info: Blue (#3b82f6)
Neutral: Gray scale (100-900)

Dark Mode:
Background: #111827 to #1f2937
Surface: #374151 to #4b5563
Text: #e5e7eb to #ffffff
```

### Typography
- **Headlines**: Bold, large font (32-48px)
- **Subheadings**: Semibold, medium font (20-24px)
- **Body**: Regular, readable font (14-16px)
- **Small**: Muted, secondary info (12-14px)
- **Font**: System fonts for performance

### Spacing
- **Compact**: 4px (internal spacing)
- **Comfortable**: 8px (element spacing)
- **Spacious**: 16px (section spacing)
- **Large**: 24px (major sections)
- **Extra Large**: 32-48px (page sections)

### Shadows
- **Subtle**: 0 1px 2px rgba(0,0,0,0.05)
- **Medium**: 0 4px 6px rgba(0,0,0,0.1)
- **Large**: 0 10px 15px rgba(0,0,0,0.1)
- **Extra Large**: 0 20px 25px rgba(0,0,0,0.1)
